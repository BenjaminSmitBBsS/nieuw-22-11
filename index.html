Demo Multi-Deploy

Eén codebase in Git origin, automatisch live op Cloudflare Vercel

Waarom deze opzet

  • GitHub is de enige bron van waarheid (origin).
  • Elke push naar main triggert een deploy op beide platformen.
  • Bewerken kan met Cursor, Cline AI, Devin AI of direct op de server.

Workflow

  1. Bewerk de code (Cursor, Cline of Devin).
  2. git add . && git commit -m "Wijziging" && git push
  3. Cloudflare en Vercel deployen binnen ±1 minuut automatisch.
